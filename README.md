# E-Cell MNNIT Official Website

[Live Site](https://ecell-mnnit.vercel.app/)

Welcome to the official repository for the E-Cell MNNIT website. This platform is the digital face of the Entrepreneurship Cell, Motilal Nehru National Institute of Technology Allahabad, designed to inform, engage, and empower students and entrepreneurs.

---

## 🚀 Features

- **Modern Responsive UI:** Built with React and Tailwind CSS for a seamless experience across devices.
- **Dynamic Event Listings:** Showcases upcoming and past events organized by E-Cell.
- **Startups Showcase:** Highlights startups associated with E-Cell MNNIT.
- **Campus Ambassador Program:** Information and certificate access for campus ambassadors.
- **Team & About:** Details about the E-Cell team, vision, and mission.
- **Contact & Socials:** Easy ways to reach out and connect.
- **Smooth Navigation:** Animated navbar, mobile-friendly overlays, and scroll-based navigation.
- **Performance Optimized:** Fast loading, optimized images, and code-splitting.
- **Deployed on Vercel:** [https://ecell-mnnit.vercel.app/](https://ecell-mnnit.vercel.app/)

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Framer Motion, React Router, React Icons
- **Backend:** (Optional, for forms/APIs) Node.js, Express.js
- **Deployment:** Vercel
- **Assets:** Custom graphics, SVGs, and images

## 🏗️ Getting Started

### Prerequisites

- Node.js (v16+ recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/E-Cell-Website.git
   cd E-Cell-Website/client
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server:**
   ```bash
   npm start
   # or
   yarn start
   ```

4. **Visit:** [http://localhost:3000](http://localhost:3000)

## 🚢 Deployment

- **Production:** Deployed on [Vercel](https://vercel.com/).
- **Preview:** [https://ecell-mnnit.vercel.app/](https://ecell-mnnit.vercel.app/)

To deploy your own fork:
1. Push your repo to GitHub.
2. Connect your repo to [Vercel](https://vercel.com/).
3. Set up build command (`npm run build`) and output directory (`build`).
